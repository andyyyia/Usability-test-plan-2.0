# Product Backlog - Usability Test Dashboard 2.0

| ID | Épica | Historia de Usuario | Prioridad (1-5) | Puntos de Historia |
|----|-------|---------------------|-----------------|--------------------|
| **US-01** | Navegación | Como usuario, quiero ver una ruta de navegación (breadcrumbs) en la parte superior para saber en qué sección del proyecto me encuentro. | Alta (1) | 3 |
| **US-02** | Feedback del Sistema | Como usuario, quiero ver un indicador visual (spinner) cuando el Dashboard está cargando datos, para saber que el sistema está trabajando. | Alta (2) | 2 |
| **US-03** | Estados Vacíos | Como usuario, quiero ver ilustraciones o íconos cuando no hay datos en una tabla o gráfico, para que la interfaz no parezca un error. | Media (3) | 3 |
| **US-04** | Jerarquía Visual | Como usuario, quiero que el botón de "Nuevo Proyecto" destaque visualmente sobre otras acciones secundarias para encontrarlo rápidamente. | Media (4) | 2 |
| **US-05** | Prevención de Errores | Como usuario, quiero que el sistema me pida confirmación antes de eliminar una observación o hallazgo para evitar borrados accidentales. | Alta (5) | 5 |
| **US-06** | Arquitectura de Información | Como usuario, quiero poder ordenar y filtrar la tabla de observaciones recientes para encontrar registros específicos fácilmente. | Baja (6) | 5 |

## Priorización de Tareas (Criterio MoSCoW)
- **Must Have (Debe tener):** US-01 (Breadcrumbs), US-02 (Feedback visual al cargar).
- **Should Have (Debería tener):** US-03 (Estados vacíos mejorados), US-05 (Confirmación de borrado).
- **Could Have (Podría tener):** US-04 (Jerarquía de botones).
- **Won't Have this time (No tendrá esta vez):** US-06 (Filtros en tabla).
